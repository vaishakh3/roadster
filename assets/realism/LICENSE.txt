Integration notes
=================
Diffuse JPEGs contain color information: use THREE.SRGBColorSpace.
Normal and roughness JPEGs are data textures: use THREE.NoColorSpace.
The normals use OpenGL (+Y) orientation, suitable for Three.js tangent-space
normal maps without inverting the green channel. Retain the same repeat,
rotation, offset and flipY settings across each corresponding material set.
Set wrapS/wrapT to RepeatWrapping. The source scale is one tile per 2 metres;
world-aligned UVs (worldDistance/2) avoid road stretch at different course lengths.
Use modest normalScale for asphalt, and an appropriate mipmapped minification
filter / anisotropy to prevent road shimmer at a grazing camera angle.
Roughness files are grayscale and can be assigned to roughnessMap directly.

Load the HDR with Three.js RGBELoader/HDRLoader. It contains linear HDR radiance,
not sRGB pixels; keep the loader's color-space/type settings. Set its mapping to
EquirectangularReflectionMapping, then generate a PMREM for scene.environment.
A 1K source is sufficient for rough body reflections and saves mobile bandwidth.
Rotate scene.environmentRotation around Y to align its brightest horizon with
the scene's key light. Its reflected architecture is not geometry in the game;
use the existing authored sky if a coherent in-game skyline is required.
